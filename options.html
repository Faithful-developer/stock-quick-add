Аккаунты

Каждый аккаунт ox-sys — отдельный профиль со своим субдоменом, токеном и локацией. Переключаются прямо в панели. Незаконченные правки сохраняются при переключении между профилями.

Видно в списке и в панели. Если пусто — показывается субдомен.

Адрес API: https://<субдомен>.ox-sys.com
Можно вставить и полный адрес из строки браузера — домен определится сам.

Cookie не требуется — достаточно токена. Токен хранится на этом компьютере в открытом виде: если тенант позволяет, используйте отдельный API-ключ, а не токен веб-сессии.

JWT из веб-приложения принимается только как Bearer; тот же токен в заголовке auth-token даёт 401. Статический ключ — наоборот.

Список загружается после сохранения доступа.

Локация по умолчанию: предвыбирается в панели, если у товара есть на ней остаток.

Endpoint коррекции остатка

По умолчанию POST /corrections — подтверждено на живом API. Количество прибавляется к остатку выбранной партии, а не заменяет его. Панель делает два запроса: создаёт коррекцию и сразу подтверждает её через POST /corrections/<id>/approve — без подтверждения остаток не меняется.

Попадает в поле reason и видно в истории коррекций ox-sys.

Смена оплаты

GET, {id} — номер продажи. Маршрут подтверждён на живом хосте. Если сервер отвечает 405, панель сама переходит на поиск по списку за дату.

PATCH. Тело собирается из ответа продажи целиком, меняется только payments[].paymentMethod; раздельная оплата не трогается.

Список для выпадающего меню. Если недоступен — подписи берутся из самой продажи.

Используется только когда продажа по номеру недоступна.
